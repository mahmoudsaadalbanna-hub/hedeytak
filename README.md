# هديتك — بداية منظمة لمتجر Vercel

## الملفات
- `public/index.html`: واجهة المتجر العربية.
- `api/orders.js`: نقطة API أولية للتحقق من بيانات الطلب وإرجاع رقم طلب تجريبي.
- `vercel.json`: إعداد Vercel.
- `package.json`: بيانات المشروع.

## مهم قبل استقبال عملاء حقيقيين
هذه النسخة ليست جاهزة للتجارة الحية بعد:
1. `/api/orders.js` لا يحفظ الطلبات في قاعدة بيانات دائمة حتى الآن.
2. الدفع بالمحفظة وفوري غير مفعّل. لا تضع مفاتيح سرية في `public/index.html`.
3. يلزم اختيار قاعدة بيانات مستضافة (مثل Postgres) وإضافة متغيرات البيئة اللازمة.
4. يلزم حساب تاجر ومفاتيح API رسمية من بوابة الدفع، والتحقق من webhook على الخادم قبل وضع حالة الطلب «مدفوع».
5. يلزم حماية لوحة الإدارة، تحديد معدل الطلبات، سياسة خصوصية وشروط بيع وشحن واضحة.
6. لا تستخدم هذه النسخة لقبول مدفوعات حقيقية قبل استكمال هذه النقاط واختبارها.

## النشر
ارفع الملفات إلى مستودع جديد أو استبدل الملفات المقابلة فقط بعد حفظ نسخة احتياطية. في Vercel، يكون `public` مجلد الملفات الثابتة وتعمل ملفات `api/*.js` كوظائف Serverless.
