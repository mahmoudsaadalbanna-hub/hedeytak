# هديتك — النسخة التجارية الأساسية

## تشغيل محلي
1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env` وضع قيمًا سرية قوية.
3. نفّذ: `npm install`
4. نفّذ: `npm start`
5. افتح الموقع على المنفذ الظاهر في الطرفية.

## مهم قبل النشر العام
- غيّر ADMIN_EMAIL وADMIN_PASSWORD وJWT_SECRET.
- استخدم استضافة تدعم Node.js وقاعدة بيانات/قرصًا دائمًا.
- فعّل HTTPS.
- اربط بوابة الدفع من حسابك أنت بعد اعتمادها.
- اربط شركة الشحن من حسابك أنت.
- لا تضع مفاتيح الدفع أو الشحن السرية داخل ملفات الواجهة.
- أضف نسخًا احتياطية ومراقبة وأمنًا إضافيًا قبل الإطلاق الكبير.

## ما هو موجود
متجر RTL، قاعدة SQLite، لوحة إدارة محمية بتوكن، منتجات، مخزون، طلبات، حالات طلب، إعدادات شحن ودفع قابلة للتحكم، ودفع عند الاستلام.

## ما لم يُفعّل تلقائيًا
الدفع الإلكتروني وشركات الشحن الحقيقية تحتاج حسابات ومفاتيح API مملوكة لك، لذلك توجد لها نقاط إعداد آمنة بدل مفاتيح وهمية.
